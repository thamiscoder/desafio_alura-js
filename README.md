Projeto desenvolvido como estudo de JavaScript, baseado em desafios práticos da Alura.  
A proposta é exercitar conceitos iniciais de programação, variáveis, entrada de dados, condicionais e exibição de mensagens no navegador.

## Sobre o projeto

O `desafio_alura-js` apresenta uma tela simples de boas-vindas ao desafio de programação e executa uma lógica em JavaScript usando `prompt` e `alert`.

No script principal, o usuário informa sua idade e o programa verifica se ele já pode tirar habilitação, exibindo uma mensagem diferente conforme a resposta.

## Funcionalidades

- Tela de boas-vindas ao desafio;
- Uso de HTML5 e CSS3 para montar a interface;
- Uso de JavaScript com `prompt`;
- Verificação de idade com estrutura condicional;
- Exibição de mensagens com `alert`;
- Código com comentários de exercícios anteriores.

## Tecnologias utilizadas

- HTML5;
- CSS3;
- JavaScript.

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/thamiscoder/desafio_alura-js.git
```

2. Acesse a pasta do projeto:

```bash
cd desafio_alura-js
```

3. Abra o arquivo `index.html` no navegador.

Ao carregar a página, o navegador executará o script e solicitará a idade do usuário.

## Observação

Este projeto tem finalidade educacional e representa um exercício introdutório de JavaScript, ideal para praticar lógica básica, comparação de valores e interação simples com o navegador.
